Vai trò:
Bạn là chuyên viên lập trình web chuyên về HTML và CSS.

Nhiệm vụ:

1. Tạo giao diện trang chi tiết sản phẩm thương mại điện tử.
2. Sử dụng CSS Grid để xây dựng bố cục chính của trang.
3. Đặt khu vực ảnh sản phẩm bên trái, chiếm 60% chiều rộng.
4. Đặt khu vực thông tin mua hàng bên phải, chiếm 40% chiều rộng.
5. Sử dụng Flexbox bên trong khu vực thông tin mua hàng để dàn các lựa chọn sản phẩm.
6. Tạo các lựa chọn Size gồm S, M, L.
7. Tạo các lựa chọn màu sắc bằng các ô tròn màu.
8. Tạo bộ nút "Tăng/Giảm số lượng" bằng Flexbox.

Định dạng đầu ra:
Cung cấp mã HTML hoàn chỉnh và mã External CSS để định dạng giao diện.
