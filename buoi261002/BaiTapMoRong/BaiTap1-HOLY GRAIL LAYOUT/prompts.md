Vai trò:
Bạn là chuyên viên lập trình web.

Nhiệm vụ:

1. Tạo bố cục website Portfolio cá nhân theo mô hình "Holy Grail Layout".
2. Xây dựng cấu trúc gồm 5 phần: Header ở trên cùng, Sidebar trái (Menu), Main Content (Nội dung chính), Sidebar phải (Quảng cáo) và Footer ở dưới cùng.
3. Sử dụng CSS Grid để xây dựng bố cục.
4. Sử dụng thuộc tính grid-template-areas để định vị 5 phần của trang.
5. Tạo nội dung giả (Placeholder) cho các khu vực của trang.
6. Đảm bảo khi nội dung trong Main Content dài ra, hai Sidebar vẫn giữ nguyên tỉ lệ chiều cao của bố cục.

Định dạng đầu ra:
Cung cấp mã HTML hoàn chỉnh và mã External CSS để định dạng giao diện.
