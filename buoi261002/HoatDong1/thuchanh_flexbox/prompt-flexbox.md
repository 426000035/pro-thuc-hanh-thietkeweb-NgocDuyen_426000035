Vai trò:
Bạn là chuyên viên lập trình web.

Nhiệm vụ:

1. Tạo màn hình đăng nhập ứng dụng quán cà phê.
2. Sử dụng CSS để định dạng giao diện.
3. Sử dụng Flexbox để căn giữa thẻ có class là 'container' theo cả chiều ngang và chiều dọc.
4. Đảm bảo thẻ 'container' có chiều cao toàn màn hình (100vh).

Định dạng đầu ra:
Cung cấp mã HTML và External CSS để định dạng giao diện.
