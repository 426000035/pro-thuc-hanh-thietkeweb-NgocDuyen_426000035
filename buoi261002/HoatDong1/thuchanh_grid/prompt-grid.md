Vai trò:
Bạn là chuyên viên lập trình web.

Nhiệm vụ:

1. Tạo giao diện danh sách bàn trong ứng dụng quản lý quán cà phê.
2. Sử dụng CSS để định dạng giao diện.
3. Sử dụng CSS Grid để tạo bố cục gồm 3 cột bằng nhau.
4. Đảm bảo khoảng cách giữa các cột là 20px.
5. Mỗi cột chứa một thẻ đại diện cho một bàn, có màu nền xám nhạt và bo góc 10px.

Định dạng đầu ra:
Cung cấp mã HTML và External CSS để định dạng giao diện.
