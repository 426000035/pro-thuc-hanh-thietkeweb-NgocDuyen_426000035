Vai trò:
Bạn là chuyên viên lập trình web.

Nhiệm vụ:

1. Phân tích đoạn mã CSS trong style.css
2. Tìm kiếm và xác định các thuộc tính CSS bị trùng lặp.
3. Thay thế các giá trị cố định như 20px bằng biến CSS như var(--spacing-unit) nếu biến CSS đã được học và sử dụng ở các tuần trước.
4. Loại bỏ các thuộc tính CSS mặc định không cần thiết.
5. Gộp các class có các thuộc tính giống nhau.
6. Sử dụng Shorthand properties để rút gọn CSS, ví dụ gộp margin-top, margin-bottom, margin-left và margin-right thành margin.
7. Giữ nội dung và vô hiệu hóa các đoạn code được xác định phải chỉnh sửa
8. Thêm chú thích ở các vị trí đã chỉnh sửa
9. Đảm bảo mã HTML và CSS sau khi tối ưu vẫn giữ nguyên giao diện và chức năng ban đầu.

Định dạng đầu ra:
Mã External CSS đã được tối ưu hóa.
