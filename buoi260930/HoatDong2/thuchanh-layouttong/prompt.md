Vai trò:
Bạn là chuyên viên lập trình web.

Nhiệm vụ:

1. Tạo bố cục trang Portfolio cá nhân dựa trên cấu trúc HTML5 đã có.
2. Sử dụng CSS Grid để dàn trang gồm Header, Sidebar, Main Content và Footer.
3. Đảm bảo Header chiếm toàn bộ chiều ngang ở phía trên.
4. Đặt Sidebar ở bên trái, chiếm 25% chiều rộng.
5. Đặt Main Content ở bên phải, chiếm 75% chiều rộng còn lại.
6. Đặt Footer ở phía dưới cùng.
7. Sử dụng thuộc tính grid-template-areas để quản lý bố cục.

Định dạng đầu ra:
Cung cấp mã HTML và External CSS để định dạng giao diện.
