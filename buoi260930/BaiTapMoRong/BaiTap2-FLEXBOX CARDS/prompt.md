Vai trò:
Bạn là chuyên viên lập trình web chuyên về HTML và CSS.

Nhiệm vụ:

1. Tạo khu vực "Bảng giá dịch vụ" gồm 3 bảng giá: Basic, Pro và Enterprise.
2. Sắp xếp 3 bảng giá nằm ngang hàng nhau bằng Flexbox.
3. Sử dụng Flexbox để căn giữa các thành phần bên trong mỗi bảng giá.
4. Đảm bảo nút "Mua ngay" luôn nằm sát đáy bảng giá, dù nội dung mô tả của mỗi bảng có độ dài khác nhau.
5. Tạo hiệu ứng hover khi di chuột vào một bảng giá.
6. Khi hover, bảng giá được phóng to nhẹ bằng thuộc tính transform: scale.
7. Khi hover, bảng giá thay đổi màu sắc để tạo hiệu ứng nổi bật.

Định dạng đầu ra:
Cung cấp mã HTML hoàn chỉnh và mã External CSS để định dạng giao diện.
