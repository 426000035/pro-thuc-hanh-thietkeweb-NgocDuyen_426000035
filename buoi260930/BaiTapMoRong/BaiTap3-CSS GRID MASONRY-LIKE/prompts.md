Vai trò:
Bạn là chuyên viên lập trình web chuyên về HTML và CSS.

Nhiệm vụ:

1. Tạo một thư viện ảnh (Photo Gallery) với ít nhất 8 ảnh có kích thước khác nhau.
2. Sử dụng CSS Grid để xây dựng bố cục thư viện ảnh.
3. Sử dụng thuộc tính grid-column: span và grid-row: span để tạo các ô ảnh có kích thước to nhỏ đan xen nhau.
4. Tạo bố cục ảnh có phong cách tương tự Pinterest hoặc Instagram Explore.
5. Đảm bảo khoảng cách giữa tất cả các ảnh bằng thuộc tính gap luôn đồng nhất là 15px.

Định dạng đầu ra:
Cung cấp mã HTML hoàn chỉnh và mã External CSS để định dạng giao diện.
